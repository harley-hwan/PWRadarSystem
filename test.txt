Part.1 : IPC(Inter Process Communication, 프로세스간 통신)

 1. 목표 : 멀티쓰레드/멀티프로세스 환경에서의 데이터 송수신 기능 구현 및 검증

    (1) 리눅스 환경에서의 쓰레드/프로세스 개념 및 통신 방법 PPT 발표 자료 작성
    (2) UDP, TCP/IP, MessageQ, 링버퍼, 공유메모리 등 IPC 개념 및 뮤텍스/세마포어 내용에 대해 PPT 발표 자료 작성(특징, 어떤 상황에서 사용하는지, 장/단점 등)
    (3) 리눅스 환경에서의 데이터 송/수신 쓰레드 구성 후 데이터를 송수신 하는 기능 구현 및 작성 코드에 대한 내용 정리 필요

         * 개발환경 : 윈도우 환경에서 Visual Studio 사용
         * 개발언어 : C언어
         * ToDo#1 : 쓰레드간 메시지 송/수신 기능 구현(전역변수 + 뮤텍스/세마포어로 구현)
         * ToDo#2 : 프로세스간 메시지 송/수신 기능 구현(메시지Q)
         * ToDo#3 : 첨부파일 활용하여 다른 사람 프로그램과 메시지 송/수신 기능 구현(TCP/IP)
                        (첨부파일은 Linux 환경에서의 TCP/IP 함수 구현해 놓은 코드임, 구현에 참고 바람)

         데이터 송신측 : 1로 초기화된 int 형 데이터를 0.1초 간격으로 송신, 데이터는 송신 후 1씩 증가(100까지)
         데이터 수신측 :  수신 받은 데이터를 출력할 수 있도록 구현
